# Portfolio Case Study Template

On Contra, high-impact case studies follow an outcome-driven format:
**Context → The Problem → The Architecture/Solution → Tangible Results & Stack.**

Use this template to prepare project descriptions before uploading them via Contra MCP.

---

## Metadata Fields (for Contra MCP)
- **Title**: `[Client / Product Name] — [Outcome-Driven Tagline]` *(Max 64 chars)*
- **Short Description**: `[One-sentence summary of what was engineered and achieved]` *(Max 300 chars)*
- **Roles**: `[Primary Role, e.g. "Full Stack Developer"]`, `[Secondary Role, e.g. "Product Designer"]` *(1–3 roles)*
- **Tools**: `[Tool 1]`, `[Tool 2]`, `[Tool 3]`, `[Tool 4]` *(1–5 tools)*
- **External Link**: `https://client-project.com`
- **Cover Image**: Public URL to a high-resolution 16:9 or 4:3 WebP/PNG image *(min 1600x1200)*

---

## Project Body Content (Markdown)

```markdown
Overview:
[A concise summary explaining what the product is, who the client/audience was, and your core responsibility.]

The Problem:
[Explain the operational challenge, market gap, or technical bottleneck that existed before you started]:
• Inefficient manual workflows: [Detail why existing solutions failed]
• Architecture limitations: [Legacy stack, slow load times, or poor UX]
• Scalability roadblocks: [Friction preventing the business from growing]

The Solution:
[Explain how you designed and engineered the solution]:
1. Strategic Architecture:
   • [Data structure, user journey, and technical roadmap]
2. High-Performance UI / UX:
   • [Figma design system, interaction design, mobile responsiveness]
3. Custom Full-Stack Engineering:
   • [Frontend framework, backend API integrations, and database design]
4. Production Deployment & Security:
   • [Edge hosting, custom domain, monitoring, and failover safeguards]

Key Engineering Highlights:
• [Measurable outcome or technical feature 1: e.g. 99/100 Lighthouse performance]
• [Measurable outcome or technical feature 2: e.g. Zero data loss with transactional guarantees]
• [Measurable outcome or technical feature 3: e.g. Reduced turnaround from days to minutes]

Tech Stack:
[List technologies, e.g. TypeScript, React, Cloudflare Workers, Postgres, Tailwind CSS]
```
