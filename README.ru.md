# Contra MCP Starter Toolkit

Клиент Node.js без внешних зависимостей, OAuth-авторизация и шаблоны для работы с [официальным удалённым MCP Contra](https://contra.com/features/mcp).

[English](README.md) · [Русский](README.ru.md)

**Для Codex и других клиентов с OAuth подключайтесь прямо к `https://contra.com/mcp`.** Репозиторий нужен для JavaScript-скриптов, работы с материалами и локальных тестов. Это библиотека-клиент, а не MCP-сервер stdio.

## Подключение Codex

В актуальной версии Codex с поддержкой удалённого MCP и OAuth выполните:

```bash
codex mcp add contra --url https://contra.com/mcp
```

Завершите авторизацию в браузере, если она откроется. Если вход не был предложен:

```bash
codex mcp login contra
codex mcp list
```

Codex сам хранит и обновляет свои OAuth-токены. Для этого способа не нужны `npm run auth`, копирование Bearer-токена или файл токенов из репозитория.

Другой способ — добавить конфигурацию в `~/.codex/config.toml` или `.codex/config.toml` доверенного проекта и выполнить `codex mcp login contra`:

```toml
[mcp_servers.contra]
url = "https://contra.com/mcp"
# Начните с трёх операций чтения.
enabled_tools = ["whoami", "list_services", "list_portfolio_projects"]
```

[Пример конфигурации](.agents/codex.config.example.toml). Если инструменты не появились, перезапустите клиент или сессию. Этот список исключает запись. Расширяйте его только под согласованную задачу после проверки текущих схем. Подтверждения клиента и процесс prepare → review → confirm остаются обязательными.

Первый запрос агенту:

> Прочитай AGENTS.md. Через Contra проверь мою учётную запись, услуги и опубликованное портфолио. Только чтение: не создавай черновики, не подтверждай изменения, не отправляй сообщения и не выполняй финансовые операции. Если доступа нет, сообщи об этом.

Источники: [MCP в Codex](https://learn.chatgpt.com/docs/extend/mcp), [команды CLI](https://learn.chatgpt.com/docs/developer-commands). Синтаксис также сверён с установленным CLI 27 октября 2026 года. Затем OAuth-вход SDK проверен на живой Contra. Вход через сам Codex отдельно не запускался.

## Другие клиенты

- **Claude Code:** `claude mcp add --transport http contra https://contra.com/mcp`, затем вход через `/mcp`. [Инструкция Claude](https://code.claude.com/docs/en/mcp).
- **Claude Desktop / web:** добавьте удалённый коннектор `https://contra.com/mcp`, если это разрешено тарифом и администратором. Не запускайте `scripts/contra-client.mjs` как сервер.
- **Cursor:** добавьте URL в `.cursor/mcp.json` и завершите OAuth в Cursor. [Инструкция Cursor](https://cursor.com/docs/mcp).

```json
{
  "mcpServers": {
    "contra": { "url": "https://contra.com/mcp" }
  }
}
```

Для Windsurf и других клиентов используйте [текущие инструкции Contra](https://contra.com/features/mcp). Пример старого формата Antigravity с `serverUrl` находится в [.agents/mcp_config.example.json](.agents/mcp_config.example.json); поддержку OAuth нужно проверить в установленной версии. SDK не синхронизирует токены с редакторами. Статический Bearer-заголовок истекает и не обеспечивает автоматическое продление.

## JavaScript SDK и команды

Нужен Node.js 18.20+ с встроенным `fetch`; на практике используйте поддерживаемую версию Node. Установка пакетов не требуется.

```bash
git clone https://github.com/alexandernevsky/contra-mcp-starter.git
cd contra-mcp-starter
npm test              # Локальные тесты, без аккаунта Contra
npm run auth          # Регистрация OAuth-клиента и согласие в браузере
npm run health        # Живая проверка чтения, без prepare/confirm
npm run tools         # Текущие имена и схемы всех страниц каталога
npm run whoami
npm run services
npm run projects
```

`auth` меняет состояние авторизации: запускайте его только для подключения SDK. Используются PKCE S256, случайный проверяемый `state` и ожидание callback до пяти минут. Callback слушает `127.0.0.1:4567`; переменная `PORT` позволяет выбрать другой порт или `0` для свободного. Успех показывается после обмена кода и проверки `whoami`. Глобальные настройки Codex, Antigravity и других редакторов не меняются.

SDK ищет токены в таком порядке:

1. Путь из `CONTRA_TOKEN_PATH`. Если он указан, но файл отсутствует, это ошибка.
2. `contra_token.json` в этом репозитории.
3. Старый `~/.gemini/config/contra_token.json`, если он существует.

`auth` сохраняет токен по `CONTRA_TOKEN_PATH` или в `contra_token.json` репозитория. Запись атомарная, права на POSIX — `0600`. На Windows ограничьте ACL файла. Файл содержит открытый текст, поэтому его нельзя добавлять в Git, чат, публичные логи или общие резервные копии. SDK не извлекает токены из хранилищ AI-клиентов.

После HTTP 401 SDK обновляет токен и повторяет запрос один раз. При неудаче исходный файл сохраняется; потребуется новый разрешённый вход. Одновременные обновления объединяются внутри процесса. Используйте **один процесс на файл токенов**: ротация между процессами не координируется. Старые Bearer-заголовки редакторов не обновляются. После сетевой ошибки, тайм-аута, 429 или 5xx автоматического повтора нет: перед повтором записи проверьте результат на Contra.

```js
import { ContraClient } from './scripts/contra-client.mjs';

const client = new ContraClient();
const tools = await client.listTools();
const me = await client.callTool('whoami');
```

Клиент выполняет MCP-инициализацию, уведомление о готовности, передаёт ID сессии и версию протокола. Поддерживает JSON и SSE. Запрашивается версия `2025-03-26`; принимаются `2025-03-26`, `2025-06-18`, `2025-11-25`. Неизвестные версии вызывают ошибку. Тайм-аут запроса вместе с чтением тела — 30 секунд; предел ответа — 16 МиБ. Это клиент инструментов без sampling, elicitation и постоянного приёма серверных событий.

## Подготовка, просмотр и подтверждение

Contra описывает двухэтапную запись и срок жизни черновика 15 минут. `prepare` создаёт состояние на сервере и **не является локальной пробой**. Запрос на проверку не разрешает создавать черновики, публиковать, отправлять сообщения или проводить платежи.

По умолчанию `callTool` / `callContraTool` разрешают только `whoami`, `list_services`, `list_portfolio_projects`. Другим инструментам нужен параметр `{ allowMutation: true }`. Это явное разрешение вызывающего кода, а не доказательство согласия человека и не изолированная среда безопасности. Низкоуровневый транспорт и прямое подключение AI-клиента этим списком не ограничены.

Для согласованного изменения:

1. Получите актуальную схему через `npm run tools` и прочитайте текущий объект.
2. Подготовьте только согласованные поля через `prepare`, явно передав `allowMutation: true`.
3. Покажите все изменения «было / станет» и получите согласие на этот предпросмотр.
4. Отдельным вызовом подтвердите возвращённый ID черновика по актуальной схеме.
5. Прочитайте результат. При истечении черновика или изменении предпросмотра подготовьте новый и получите согласие заново.

```js
const draft = await client.callTool(
  'update_productized_service_prepare',
  reviewedUpdateArguments,
  { allowMutation: true },
);
console.log(draft); // Только локальный просмотр, без публичных логов.
// Здесь остановитесь для согласования. Автоматического confirm нет.
```

[Пример подготовки услуги](scripts/examples/prepare-service-update.mjs) требует `--prepare SERVICE_SLUG`, не выбирает первую услугу сам и ничего не подтверждает. Пустое обновление может быть отклонено текущей схемой; это не тест подключения.

Считайте массивы и блоки содержимого полной заменой, если текущая схема явно не говорит обратного. Сохраняйте пропущенные поля и идентификаторы. Тексты и цены шаблонов — примеры, а не факты о владельце или разрешение на публикацию.

## Возможности и проверка актуальности

[Официальная страница Contra MCP](https://contra.com/features/mcp) описывает работу с портфолио, услугами, наймом, сообщениями, счетами и платёжными ссылками. Актуальные инструменты определяются через `tools/list` конкретного аккаунта. Число «119» из прежнего README было историческим наблюдением.

Ограничения видеообложек, тегов профиля, форматов slug и редактирования community-постов нужно сверять с живой схемой. Старые наблюдения не доказывают, что возможность до сих пор отсутствует. Не придумывайте API и не переходите к записи через браузер без разрешения.

[Результаты проверки](docs/VERIFICATION.md) содержат дату и ограничения. `npm test` работает локально. `npm run health` отдельно проверяет чтение и выводит только количества и признаки успеха. `npm run projects` включает черновики, максимум 25 записей; health читает только опубликованные проекты, максимум 10. Это не полная выгрузка портфолио.
